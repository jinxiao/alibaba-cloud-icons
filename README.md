# Alibaba Cloud Icons — compatibility publisher

[简体中文](README.zh-CN.md) · [Browse icons](https://jinxiao.github.io/alibaba-cloud-icons/)

Alibaba Cloud Icons and Software Icons are now maintained together in
[jinxiao/drawio-software-icons](https://github.com/jinxiao/drawio-software-icons).
The unified gallery contains 444 software icons and 888 Alibaba Cloud icon entries,
organized into two collections and 17 categories, with English and Chinese browsing.
Alibaba counts include color variants and supplemental UI symbols.

**Both original sites remain available:**

- https://jinxiao.github.io/alibaba-cloud-icons/ — defaults to Alibaba Cloud.
- https://jinxiao.github.io/drawio-software-icons/ — defaults to General Software.

This repository keeps the original Alibaba Pages address and resource paths alive.
Its workflow checks the source repository's latest successful publication hourly
(GitHub may delay schedules), or on manual dispatch, and builds that exact commit's
Alibaba-compatible target. Unchanged published commits are skipped. Do not rename,
delete or archive this repository while this publishing workflow is needed.

Old XML, SVG, configuration JSON, plugin, catalog and ZIP URLs remain supported.
The source files retained here are historical; submit artwork, website and build
changes to the main repository, under `collections/alibaba-cloud/` for Alibaba data.
The workflow template lives in `deployment/alibaba-pages.yml` in the main repository.

For Desktop, use **Categories / desktop setup** in the gallery to generate an offline
configuration or merge it with existing JSON from **Extras → Configuration**.
No custom JS plugin is required. The original plugin remains available for
compatible self-hosted installations.
