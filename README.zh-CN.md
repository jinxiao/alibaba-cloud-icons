# 阿里云图标 — 兼容发布仓库

[English](README.md) · [在线图标库](https://jinxiao.github.io/alibaba-cloud-icons/)

阿里云图标与软件图标现统一维护于
[jinxiao/drawio-software-icons](https://github.com/jinxiao/drawio-software-icons)。
合并后包含 444 个软件图标、888 个阿里云图标条目，两个图标集、17 个分类，支持中英文。
阿里云条目包含颜色变体与 UI 补充图形，不代表 888 种独立云服务。

两个旧网址继续保留：

- https://jinxiao.github.io/alibaba-cloud-icons/ 默认展示阿里云。
- https://jinxiao.github.io/drawio-software-icons/ 默认展示软件与品牌。

当前仓库负责保留阿里云旧网址与资源路径。工作流每小时检查主仓库最近一次发布成功的版本
（GitHub 定时任务可能延迟），按提交号构建并发布；也可手动同步，已发布且未变化的版本跳过。
请勿重命名、删除或归档此仓库，以免影响 Pages 或定时发布。

旧 XML、SVG、配置 JSON、插件、目录数据和 ZIP 地址保持兼容。仓库中保留的旧源码仅供历史参考；
图标、网站和构建修改请提交到主仓库，阿里云数据位于 `collections/alibaba-cloud/`。
工作流模板位于主仓库 `deployment/alibaba-pages.yml`。

桌面端在网站打开「选择分类 / 桌面配置」，可以生成离线 JSON，也可以粘贴客户端
「其他 → 配置」中的已有 JSON 进行合并，无需安装 JS 插件。原插件继续为兼容的自托管版本提供。
